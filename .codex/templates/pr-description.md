# PR Description Template

The final PR description must be emitted as one fenced markdown code block:

````markdown
```markdown
## Added
- 

## Changed
- 

## Fixed
- 

## Improved
- 

## Key Code Mentions
- 

## Testing
- 

## Legal/Data Notes
- 
```
````

Use short, plain statements. Keep empty sections only when they make the scope clearer; otherwise write `None`.
